# Algorithm for File Updates in Python

## Project Description
This project demonstrates the development of a Python algorithm used to maintain an IP allow list for a healthcare organization's restricted network.

The algorithm:
- Reads an allow list from a text file
- Converts the file contents into a list
- Compares the allow list against a remove list
- Removes unauthorized IP addresses
- Updates the original file with the revised allow list

## Skills Demonstrated
- Python file handling
- Reading and writing text files
- Lists and string manipulation
- Loops and conditional statements
- Function creation
- Cybersecurity access control concepts
